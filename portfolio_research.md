## My dream recruiter reaction

"This candidate builds polished, real-world projects, writes clean code, and pays attention to details. I want to interview them."

## Success Criteria

- Lighthouse score above 90
- Fully responsive
- Semantic HTML
- Accessible
- Clean Git history
- Organized CSS
- Mobile-first mindset
- Every project has a GitHub link
- Every design choice has a reason

## Portfolio Principles

1. Simplicity over complexity.
2. Every section must have a purpose.
3. Every animation should improve the experience.
4. Content is more important than decoration.
5. Accessibility is not optional.
6. Mobile experience is as important as desktop.
7. Recruiters should understand who I am within 30 seconds.
8. Code should be clean enough that I'm proud to show the repository.
