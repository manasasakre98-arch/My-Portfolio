# Portfolio

Personal portfolio website showcasing my projects, technical skills, certifications, education, and learning journey as a Computer Science undergraduate.

---

## Overview

This portfolio represents my journey as a Computer Science undergraduate interested in software development, computer vision, problem solving, and full stack development.

I built the website from scratch using HTML, CSS, and JavaScript with the goal of creating a professional, responsive, accessible, and easy-to-navigate experience.

The portfolio focuses on the work itself rather than unnecessary visual effects, while allowing my projects, skills, education, certifications, and current learning direction to speak for themselves.

## Design Inspiration

The visual direction of this portfolio is inspired by modern developer portfolios that prioritize typography, spacing, readability, and content over excessive decoration.

The design principles include:

- Minimal dark interface
- Lavender accent color
- Strong typography
- Clear visual hierarchy
- Controlled whitespace
- Simple cards
- Consistent spacing
- Responsive layouts
- Minimal animation
- Recruiter-friendly navigation

The portfolio takes inspiration from clean professional portfolio design without copying another website's exact layout, colors, wording, components, or visual identity.

The main goal is to make the website feel professional and intentional while keeping the focus on my work.

---

## Development Journey

This portfolio started as a simple HTML page and gradually evolved into a responsive personal website.

During development, I worked through:

1. Structuring the website using semantic HTML
2. Creating the visual system with CSS
3. Building responsive layouts
4. Implementing a mobile navigation menu with JavaScript
5. Adding smooth scrolling
6. Organizing technical skills into meaningful categories
7. Creating project showcase cards
8. Building an education and learning timeline
9. Adding certification and credential links
10. Connecting my resume and professional profiles
11. Refining spacing, typography, navigation, and responsive behavior

The project also helped me understand how HTML, CSS, and JavaScript work together instead of treating them as separate technologies.

I am continuing to improve the portfolio as I build new projects and develop my technical skills.
